## 1. 范围

v1.0.0 是一次完全重构，只兼容 **DSH 0.2.2-rc.3**。

纳入：
- 免费搜索引擎：Bing（默认）、AnySearch、SearXNG、DuckDuckGo HTML、DuckDuckGo Lite。
- 自动回退、时间范围、结果缓存、结果归一化。
- 可选搜索增强（默认关闭；当前 Agent 模型 + 可选 `provider:model` 覆盖）。
- 8 个平台：GitHub / V2EX / Bilibili / Reddit / HN / Stack Overflow / Wikipedia / npm。
- 3 个 Agent 工具：`free_search_test` / `platform_search` / `advanced_search`。
- 插件页配置 + `/thin-search-engine` 命令。
- 全局 provider 热切换：通过 `ConfigForms.get('web')` 设置 `searchProvider`。

不纳入：
- UI “测试引擎”按钮、模型下拉选择器。
- 自定义 HTTP bridge、profile patch 写入、插件级代理。
- 0.1.x / 0.2.0 / 0.2.1 兼容分支。
- `remote.session.events`、`inputActions`、`conversation.input.for`：本插件不渲染会话行、不注入输入动作、不使用 session events，不纳入依赖核实范围。

## 4. Host 设计

- `WebSearchProvider`：`id: "thin-search"`、`title: "Thin Search"`、本地化 `description`、`available() => true`；不实现 `ready()`。
- 引擎链：Bing 默认 → AnySearch → SearXNG → DDG → DDG Lite；有时间过滤时 SearXNG/DDG 优先。
- 每引擎独立超时 + 总预算；只重试网络/5xx；202/403/captcha 直接失败并回退。
- 结果：`url` 只允许 http(s)；`title` / `snippet` / `summary` / `publishedAt`。
- 缓存：`cacheTtl` 分钟，0 关闭；**先查缓存，再增强**；命中缓存不调用 LLM。
- 时间范围：固定档、相对值、绝对日期；绝对日期换算为距今天数。
- 增强：`ctx.agents.currentInitiator()?.model.current()`；`enhanceModel` 可覆盖；无模型时跳过。
- 错误：使用 `WebError`（来自 `@deepseek-ai/dsh-web`）和明确 code；取消时传播 `AbortSignal`。

## 5. 配置

`cordis.patch.yml` 的 `thin-search` 行只保留小字段：

| 字段 | 默认 | 说明 |
|---|---|---|
| `provider` | `bing` | 首选引擎 |
| `platforms` | 全部 8 个 | 平台启用列表 |
| `cacheTtl` | `5` | 0 关闭；移除旧 `cache` |
| `searchEnhance` | `false` | 增强开关 |
| `enhanceModel` | `""` | 空 = 当前 Agent 模型 |
| `enhanceSystemPromptPath` | `""` | 空 = 内置默认；支持 `~/...` 或绝对路径 |
| `bingMarket` | `zh-CN` | Bing 市场 |
| `region` | `""` | DDG 区域 |
| `searxngInstances` | `[]` | 自定义 SearXNG 实例 |

- 大文本提示词放插件数据文件（默认建议 `~/.dsh/thin-search/system-prompt.md`），不进 `cordis.patch.yml`。
- 移除 `proxy`：使用 DSH `dsh-http-proxy` 的 `HTTP_PROXY/HTTPS_PROXY` 全局策略。
- 旧 `enhanceSystemPrompt` 不读取；README/CHANGELOG 说明迁移。

## 6. Client 设计

- `plugins.bundle.config` key：`dsh-thin-search`（bundle 包名），由 `ctx.configForms.whileServed(['thin-search'], ...)` 守卫；入口在“插件 → 已安装 → dsh-thin-search → 配置”，没有全局 Settings 项。
- 页面不接收 owner form props：runtime 自行 `configForms.get('thin-search')`，每个控件通过 `ConfigForm.set` 立即写入；无 Save/Discard 栏。
- 全局 provider 卡片：`ctx.remote.web.listProviders()` + `ctx.configForms.get('web').set('searchProvider', id)`。
- 页面卡片：全局搜索提供方、首选引擎、搜索增强、平台搜索、高级设置。
- 无 UI 测试按钮；保留 `/thin-search-engine` 命令，用 `configForms.get('thin-search').set('provider', id)`。
- `ctx.locale` 提供 en/zh；theme token；可访问控件（不嵌套 button，不用 span onClick，label/role/键盘）。
- 不 import 其他 DSH Client 包；只用 React、react/jsx-runtime 基线模块。

## 7. 工具

- 名称保持 `free_search_test` / `platform_search` / `advanced_search`。
- `execute(args, exec)` 必须转发 `exec.signal`，声明 `timeoutMs`。
- `output.render` 返回 `ContentBlock[]`，不依赖 `finalizeContent`。
- 平台限制写入描述：V2EX 仅热帖；Bilibili/Reddit 可能受风控。
